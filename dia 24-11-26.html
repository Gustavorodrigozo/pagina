Resumen dia 24-11-26

Este es el resumen del día 24 de noviembre de 2026. En la guia para aprender programacion web desde cero sugieren iniciar con HTML y CSS, luego pasar a JavaScript.

  1. Este dia aprendi sobre los fundamentos de HTML y CSS.
  2. Html para dar la estructura a las páginas web y CSS para darles estilo.
  3. Aprendi como crear links en HTML tanto a sitios externos como a secciones internas de la misma página.
  4. Aprendi como crear listas en HTML y CSS tanto ordenadas como no ordenadas y crear inputs de tipo texto, radio y checkbox, ademas de aprender sobre la importancia de la semántica en HTML.
  5. Ademas aprendi sobre el uso de CSS para personalizar la pagina web usando selectores y propiedades y modelo de caja en CSS y cómo controlar el espacio entre elementos.
